# Security Policy

## Reporting a security issue

Do not disclose suspected vulnerabilities, credentials, private keys, non-public contact data, relationship history, personal assessments, or exploitation details in a public issue.

Report concerns privately to `info@bhoctherapeutics.com` with the affected file or URL, reproduction steps, impact, and supporting evidence.

## Public-data boundary

This repository is public. It may contain only verified public professional identity, organisation, role, public professional contact routes, and public-source evidence. Private relationship tracking, internal priority, outreach state, review queues, inferred familiarity, credentials, and confidential notes belong only in the approved private workspace.

## Supported version

Security fixes apply to the current `main` branch. The former browser directory is not a supported deployment.
